# 《자정 주파수》 — 개발 데모

폭우가 쏟아지는 밤, 폐쇄 방송국의 불법 음성 복원 실험을 조사하다 고립된 동생 하윤을 찾는 한국어 1인칭 포인트앤클릭 미스터리 게임입니다. 플레이어는 실제 기록과 합성 음성을 구별하고, 확보한 증거를 어떻게 처리할지 결정합니다.

방송국의 낡은 송신기는 사람들의 기억을 지우는 방송을 반복합니다. 먼저 88.0 MHz 호출이 합성임을 확인한 뒤, 전력실·보관실·녹음실의 세 갈래 중 원하는 순서로 두 곳을 조사합니다. 차단기·시간축·빛 혼합은 서로 다른 조작을 사용하며, 두 경로의 순서와 건너뛴 경로가 옥상 증거 요약과 결말에 기록됩니다.

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm test
npm run typecheck
npm run build
MIDNIGHT_URL=http://127.0.0.1:5174 npm run qa:uiux
npm audit
```

`npm run qa:uiux`는 실행 중인 개발 서버(`MIDNIGHT_URL`로 지정)를 대상으로 실제 시작→가까이 보기→도구 획득→장소 이동과 데스크톱→세로폰→가로폰→세로폰 전환, 저장 복원, 36×36px 핵심 터치 영역, viewport/overflow, console/HTTP 오류를 검사하고 `qa-art/ui-ux-contract/`에 JSON 및 스크린샷 증거를 저장합니다. 제품 목표와 P0 합격 기준은 `UI_UX_GOAL.md`가 소유합니다.

## 조작

- 화면 좌우 영역 아무 곳, 좌우 화살표 또는 `A`/`D`, 키보드 방향키: 장소 이동. 첫 플레이 화면에 클릭 영역 안내가 한 번 표시됨
- 화면의 조사 구역: 장비나 단서를 가까이 보기
- 가까이 보기에서 책상·선반·벽 틈 등에 놓인 실제 도구 그림: 해당 도구 수집
- 현장 가방의 아이템 그림: 큰 그림과 긴 조사 기록 열기
- 퍼즐판의 다이얼·회로 스위치·테이프·빛 슬라이더: 장비마다 다른 방식으로 직접 조작
- 상단 `엔딩` 또는 시작 화면 `엔딩 갤러리`: 확인한 결말 다시 보기
- `Escape`: 아이템 상세 → 가방 → 확대 장소 순으로 가장 위 화면부터 한 단계씩 돌아가기
- 퍼즐 해결 카드·확대 조사·가방·아이템 상세·엔딩 갤러리: 어두운 바깥 화면을 눌러 닫기. 닫을 수 있는 화면에는 흐린 안내 문구가 표시됨
- 자정까지 30분이라는 설정은 서사적 긴장 장치이며 실제 제한시간은 없음
- 옥상 최종 선택 전 핵심 사실, 플레이어가 믿거나 의심한 기억, 잠긴 결말의 조건을 한 화면에서 요약
- 자동 저장, 초기화, 키보드·마우스·터치 지원
- 폰에서 모든 수집 도구를 얻으면 장면 왼쪽 위에 사진과 이름만 있는 최대 108px 미니 토스트가 부드럽게 나타났다 사라지며, 누르면 즉시 닫힘. 도구·엔딩 이미지는 시작 시 미리 불러 지연을 줄이고 데스크톱 획득 카드는 기존 크기·내용·시간을 유지
- 상단 `가로 전체` 버튼: 사용자 조작으로 전체화면을 요청한 뒤 지원되는 모바일 브라우저에서는 가로 방향을 잠금. 폰에서 미지원·거부될 때는 실패 팝업을 표시하지 않으며 세로 화면으로도 계속 플레이하고 직접 기기를 돌릴 수 있음
- 상단 `전체` 버튼과 `BGM` 슬라이더: 전체 음향을 즉시 끄거나, 48초 CC0 공포 BGM만 0–100으로 드래그 조절할 수 있음. 작게 깔리는 부드러운 태풍 빗결·저역 돌풍, 전기 험·장소별 방송 주파수, 핵심 사건 효과음, 허상 엔딩 비명을 포함함. 주파수 다이얼은 88.0 MHz에 가까워질수록 잡음이 줄고 반송파가 선명해지며, 차단기·테이프·빛 조절기에는 BGM보다 선명한 물리 조작음이 있음. 퍼즐 해결음은 기존 저음 효과 대신 작고 짧은 단계별 상승 신호로 바뀌며 모든 음량 설정은 브라우저에 저장됨

## 이야기

음향 복원 기사 **하윤**은 폐쇄된 해월 제7중계소가 재난 통화에서 가족 목소리를 합성하고 청취자의 최근 기억을 덮어쓴다는 증거를 찾다가 옥상에 고립됩니다. 주인공은 하윤의 실제 전화 직후 방송국에 도착합니다.

> “오빠, 목소리를 따라오지 마. 숨과 방의 울림을 확인해.”

방송국은 과거 가족 통화를 잘라 만든 88.0 MHz 구조 호출과 “하윤은 23:40에 떠났다”는 거짓 퇴장 방송을 반복합니다. 그러나 23:55 실제 경고 릴, 23:58 옥상 사진, 정비 통로의 붉은 흙과 발자국은 하윤이 실제로 안에 있음을 서로 독립적으로 증명합니다.

목표는 간단합니다.

1. 방송국 안으로 들어간다.
2. 전력을 복구한다.
3. 동생이 남긴 녹음을 찾는다.
4. 숨은 통로를 연다.
5. 마지막 거짓 방송을 송신기에서 빼고 옥상에서 동생을 찾는다.

## 퍼즐 구성

- **주파수 조율:** 80–92 MHz 다이얼을 돌리며 신호 막대와 목소리가 강해지는 지점을 찾는다.
- **비상 전력 분배:** 전력 세 칸으로 구조에 필요한 회로 세 개만 골라 켠다.
- **녹음 순서 배열:** 네 테이프의 녹음 내용을 시간순으로 놓는다.
- **빛 혼합:** 청록·호박·빨강의 광량을 각각 조절해 벽의 숨은 문양을 완성한다.
- **거짓 방송 판별:** 지금까지 확인한 사실과 다른 문장 하나를 송신기에서 뺀다.

아이템을 모두 모아도 퍼즐은 자동으로 풀리지 않습니다. 잘못 조작하면 퍼즐이 반응하며, 주변 단서를 이해해야 풀 수 있습니다.

- **병렬 경로 조사:** 88.0 MHz를 확인하면 전력실(회로 선택)·보관실(시간 순서)·녹음실(RGB 광량) 세 경로가 동시에 열립니다. 원하는 순서로 두 곳만 해결해 숨은 통로를 열 수 있고, 해결 순서·선택하지 않은 경로·경로별 증거는 저장되어 옥상 요약과 결말 문맥에 반영됩니다.

- 퍼즐을 풀 때마다 구조 신호 복구 카드, 새 하윤 대사와 다음 목표가 즉시 나타납니다.
- 발견한 기록을 물리적 맥락과 함께 `증거로 보존`하거나 `합성 가능성으로 격리`합니다. 이 분류가 옥상에서 구조·전체 삭제·공개 방송·오판 중 가능한 행동을 바꿉니다.
- 휴대 라디오부터 기억 테이프까지 수집 가능한 도구 11종은 전용 그림이 각 장면의 책상·콘솔·선반·벽 틈·사다리 옆에 직접 놓입니다. 가방에서 그림을 확대하고 90자 이상의 개별 조사 기록을 읽을 수 있습니다.
- 일반 결말 3개와 숨겨진 **오판** 결말이 있습니다. 숨겨진 결말은 세 기록을 모두 합성으로 격리한 회차에서만 열리며, 실제 하윤을 합성 음성으로 오인하는 공포 화면과 비명 연출을 포함합니다.
- 확인한 결말은 별도 갤러리에 영구 기록되므로 진행을 초기화해도 사라지지 않습니다.
- 진행 상황은 v10 형식으로 자동 저장되며, 손상되거나 조작된 값은 안전하게 초기화됩니다.

## 결말과 갤러리

- **구조:** 사진·실제 경고 릴·발자국을 따라 옥상의 하윤을 구조하고 송신기를 파괴한다.
- **잃은 기억:** 합성과 원본을 구분하지 않고 모두 삭제해 하윤의 실제 경고와 목적까지 잃는다.
- **공개 방송:** 실제 경고 릴, 합성 파형, 사진·출입 시각을 비교 가능한 증거 묶음으로 88.0 비상망에 송출한다. 산 아래 수신국이 위치를 역추적해 두 사람을 구조하고 실험을 외부에 입증한다.
- **오판:** 모든 기록을 합성으로 격리한 탓에 옥상의 실제 하윤까지 허상으로 오인하고 접근하지 않는다.

일반 결말 세 개도 각각 별도의 1280×720 시네마틱 이미지와 세 장면 분량의 후일담을 사용합니다. 구조는 폭풍이 걷히는 산길과 구조 차량, 잃은 기억은 빈 사진과 유리 너머의 하윤, 공개 방송은 청록·호박 두 파형과 계곡의 응답 불빛으로 구분됩니다. 엔딩 화면은 느린 카메라 이동, 레터박스, 순차 자막과 결말별 색보정을 사용합니다.

`오판` 선택은 클릭 즉시 미리 불러 둔 비명의 선행 무음 뒤부터 재생하고 전체 화면 점프스케어로 전환합니다. 연출이 끝나면 전체 화면도 자동으로 해제됩니다.

갤러리는 `midnight-frequency-endings-v1`에 진행 저장과 별도로 기록됩니다. 잠긴 카드는 조건을 직접 스포일러하지 않고 실루엣으로 남으며, 확인한 카드를 누르면 전용 이미지·후일담·순차 자막을 언제든 다시 볼 수 있습니다. 폰 갤러리는 세로 2×2, 가로 1×4로 네 결말 사진을 스크롤 없이 한 번에 표시하며, 해금 즉시 카드 사진을 보여 줍니다.

메인 UI는 깨끗한 대시보드 대신 검정·핏빛 적색·산화된 갈색이 섞인 낡은 방송 장비를 닮은 비대칭 패널을 사용합니다. 헤더와 조작부에는 얼룩진 금속 점식, 녹 가장자리, 미세한 아날로그 노이즈·주사선과 경고색을 겹치고 위험 단계에서만 제한적인 화면 깜빡임을 사용합니다. `가까이 보기`의 확대 배경은 원래의 차가운 폭풍 색을 유지하고, 검정 비네트와 낮은 불투명도의 가장자리 부식·긁힘·녹 얼룩만 더합니다. 도구 표식과 퍼즐 패널은 적갈색으로 노후화해 일반 탐색과 구분합니다. 전체 UI 크기·간격은 기존보다 소폭 줄였고 마지막 옥상 선택 패널은 요약·선택지 밀도를 별도로 낮춰 100% 배율과 짧은 화면에서도 버튼이 잘리지 않게 했습니다. 폰 회전·전체화면 상태 변화는 전체 게임 DOM을 재생성하지 않고 관련 버튼과 상태만 갱신해 조사·갤러리 화면을 유지합니다. `prefers-reduced-motion`에서는 반복 흔들림을 제거합니다.

## 미술

- Grok 4.5가 방송국 배경의 통일된 미술 방향과 10개 장면의 이미지 생성 프롬프트를 만들었습니다.
- 사용자가 승인한 현재 고해상도 이미지 생성기로 프롬프트를 이미지로 만들었습니다.
- 탐색 장면 10개와 일반 엔딩 이미지 3개는 1280×720 WebP 파일로 저장되어 있으며, 게임 실행 중에는 이미지 API를 사용하지 않습니다.
- 탐색 배경 영역은 데스크톱에서 브라우저 폭 전체와 사용 가능한 세로 공간을 채웁니다. 배경 이미지는 `cover` 비율을 유지하고 장소 제목·메시지·신호·이동·조사 버튼은 기존 기준점에 고정됩니다.
- 하윤의 즉석사진은 1254×1254 WebP로 새로 제작했으며 아이템 확대·갤러리·허상 엔딩에 같은 얼굴을 사용합니다.
- 허상 엔딩은 정상 사진과 분리된 1254×1254 공포 변형 WebP와 SoundBible에서 받은 2.82초 Public Domain MP3를 로컬 자산으로 재생합니다.
- 문자·숫자·로고·UI·잔인한 장면·불필요한 인물이 없는지 전체 이미지를 모아 확인했습니다.

## 프로젝트 구조

- `src/engine.ts`: 진행, 퍼즐 상태, 저장과 결말을 다루는 순수 상태 엔진
- `src/main.ts`: 탐험 화면, 퍼즐판, 도움말, 입력 처리
- `src/soundscape.ts`: CC0 BGM·핵심 상호작용 효과음과 절차적 빗소리·전기 험·장소별 주파수를 한 음향 토글로 제어
- `src/style.css`: 방송국 장면, 물리 퍼즐 조작부, 반응형 연출
- `src/engine.test.ts`: 오답과 정답, 잠금 해제, 저장, 전체 결말 경로 검증
- `public/art/radio/`: 방송국 장면 10개와 수집품 그림 11개
- `public/audio/`: CC0 공포 BGM·핵심 상호작용 효과음과 허상 엔딩 전용 Public Domain 비명
- `THIRD_PARTY_ASSETS.md`: 외부 자산 출처·사용 조건·검증 해시
- `DEVELOPMENT_LOG.md`: 콘셉트 변경과 검증 기록
- `PROCESS_HYGIENE.md`: 개발 서버·QA 브라우저 소유권, PID·포트 원장, finally 종료와 RAM 검증 절차
- `NARRATIVE_DESIGN.md`: 정답 사실, 사건 시간표, 세 단서 규칙, 엔딩별 행동·근거·결과와 외부 설계 근거

검증된 정적 빌드는 별도 공개 저장소 `altakori/undecided-character-playtest`를 통해 GitHub Pages에 배포합니다. 개발 브랜치와 기록은 이 비공개 원본 저장소에 유지합니다.

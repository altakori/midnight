# 자정 주파수 — 공개 플레이테스트

폭우가 쏟아지는 밤, 폐쇄 방송국의 음성·기억 조작 증거를 조사하다 옥상에 고립된 동생 하윤을 찾는 한국어 1인칭 포인트앤클릭 미스터리 게임입니다. 실제 기록과 합성 음성을 구별하고 증거를 어떻게 처리할지 결정합니다.

## 플레이

**https://altakori.github.io/midnight/**

- 데스크톱과 모바일 브라우저 지원. 폰에서는 `가로 전체` 버튼 또는 직접 회전으로 가로 화면 권장
- 키보드·마우스·터치 지원
- 폰에서 모든 수집 도구 알림은 장면 왼쪽 위에 사진과 이름만 있는 108px 미니 토스트로 부드럽게 표시되고, 세로·가로 모두 같은 크기를 유지하며 누르면 즉시 사라짐
- 세로·가로 회전과 전체화면 변화는 현재 조사·갤러리 DOM을 유지하고, 이전·다음 화살표와 글자는 박스 안에 고정
- 폰 엔딩 갤러리는 세로 2×2·가로 1×4로 네 사진을 한 화면에 표시하며, 도구·엔딩 이미지는 시작 시 미리 로드
- 녹음 순서를 클릭해도 퍼즐 패널의 스크롤 위치를 유지. 가로 잠금 미지원·거부 팝업은 표시하지 않음
- 진행 상황과 확인한 엔딩은 현재 브라우저에 자동 저장
- 공포 이미지, 짧은 비명과 음향 연출 포함
- 브라우저 정책상 첫 클릭 이후 음향이 시작될 수 있음

## 테스트 피드백

버그, 잘린 UI, 이해하기 어려운 단서·엔딩, 공개 방송의 목적, 음량 문제, 재미가 떨어지는 구간을 발견하면 [GitHub Issues](https://github.com/altakori/midnight/issues)에 남겨 주세요.

가능하면 다음 정보를 포함해 주세요.

1. 사용 기기와 브라우저
2. 문제가 발생한 장소 또는 퍼즐
3. 재현 순서
4. 예상한 결과와 실제 결과
5. 스크린샷

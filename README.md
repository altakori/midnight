# 각주 소녀 탈옥

최종 인쇄까지 9분. 삭제된 각주 소녀를 원고 밖으로 빼내기 위해 **어떤 동사를 반복하고 어떤 동사를 끝까지 살려둘지** 계획하는 5–8분 한국어 인터랙티브 퍼즐입니다.

## 핵심 플레이

- 다섯 번의 행동으로 세 검문을 통과하며 시간·의심·소녀의 신뢰를 관리합니다.
- 동사는 사용 횟수에 따라 `기록 → 경고 → 추가 비용 → 삭제`로 변합니다.
- 같은 안전한 행동을 반복하면 당장은 편하지만 최종 탈출에 필요한 동사를 잃습니다.
- 초반에 소녀의 신뢰를 얻지 못하면 2차 검문의 공개 선택지가 실제로 잠깁니다.
- 삭제된 동사는 장부에서 수정액으로 복원할 수 있지만 시간 2분과 의심 2를 지불합니다.
- 마지막 문은 모순 조합으로만 열립니다.
  - 조용한 탈출: `숨기기 + 드러내기`
  - 공개 탈출: `믿기 + 위조하기`, 신뢰 3 이상
- 의심 8, 시간 0, 잘못된 최종 선택은 각각 다른 실패로 이어집니다.
- 모든 선택 직후 빨간 편집 메모와 동사 장부가 왜 미래가 바뀌었는지 보여줍니다.
- 선택지 포커스/호버에서는 예상 행동 삽화와 수치 변화를, 선택 후에는 실제 동사·위험 상태 삽화를 선택지 위에 표시합니다.

## 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:5173/` 주소를 브라우저에서 엽니다.

## 검증

```bash
npm test
npx tsc --noEmit
npm run build
```

- `src/engine.ts`: 순수 상태 전이, 자원 판정, 동사 단계, 수정액, 결말, 저장
- `src/content.ts`: 검문 장면과 분기 선택
- `src/main.ts`: 동사 장부, 접근 가능한 DOM UI, localStorage 이어하기/재시작
- `src/style.css`: 종이·활자·빨간 교정 UI와 반응형 레이아웃
- `public/art/footnote-girl.webp`: Grok이 설계한 미술 프롬프트로 제작한 각주 소녀 원고 삽화
- `public/art/state/*.webp`: 여섯 동사와 네 위험 상태를 보여주는 Grok 아트 디렉션 기반 상태 삽화

저장 데이터는 브라우저 `localStorage`의 `footnote-girl-escape-save`에 버전과 함께 보관됩니다. 외부 런타임 에셋은 사용하지 않습니다.
